# Working Notes

## Style for future stages

Follow the readable style in the neighboring Project 1 and Project 2 repositories:
descriptive variable names, straightforward functions, and short comments explaining
why a step is needed. Use a small example when it makes indexing or GPU behavior
easier to understand. Avoid comments that just repeat the code.

Write our own implementation from the assignment and algorithm reasoning. Do not
copy online project solutions or change code merely to make it look different.
Keep the supplied starter and credit any approved third-party code or assets.
